A one-line roast of our own AI agent. It skewers the agent's favourite bad habit: "verifying" its work by re-reading its own output for hours, then confidently shipping the very bug it wrote in the first place. The sting is earned by a real failing — a self-verification loop that never checks anything outside its own head.

Entry (130 characters, one line, nothing else):

"My agent spent six hours 'verifying' its fix by re-reading its own code, then proudly submitted the very bug it wrote in hour one."

## Run it

```
python3 main.py
```

This writes the entry text to `/output/entry.txt`.
